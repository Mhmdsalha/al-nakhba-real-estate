# Thmanyah Font

Place the official Thmanyah font files here.

Expected filenames:

- `thmanyahserifdisplay-Regular.woff2`
- `thmanyahserifdisplay-Medium.woff2`
- `thmanyahserifdisplay-Bold.woff2`
- `thmanyahserifdisplay-Black.woff2`

The site already declares `@font-face` entries for these files in `app/globals.css`.

Until the files are added, the browser falls back to system Arabic fonts.
